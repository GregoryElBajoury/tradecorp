# TradeCorp International - Pipeline ETL Big Data & DevOps

> Projet d'ingénierie des données et d'industrialisation (Jalons 1 à 5).

En cours

##  Structure du Projet
- `data/` : Fichiers CSV bruts (Northwind) et sorties Parquet.
- `notebooks/` : Notebooks Jupyter d'exploration, nettoyage et transformation (PySpark).
- `src/` : Modules Python modulaires (`reader.py`, `transformer.py`, `writer.py`, `pipeline.py`).
- `tests/` : Tests unitaires avec Pytest.
